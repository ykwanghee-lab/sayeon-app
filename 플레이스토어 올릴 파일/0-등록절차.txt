■ Play Console 순서
1. https://play.google.com/console → 앱 만들기 → 이름 "사연이짱 - 인생 사연 모아보기", 앱, 무료
2. 대시보드 "앱 설정" 항목 전부 작성
   - 개인정보처리방침 URL 입력
   - 앱 액세스 권한: 제한 없음 / 광고: 없음 / 콘텐츠 등급 설문 / 타겟층: 18세 이상
   - 데이터 보안: 수집·공유 데이터 없음
3. 기본 스토어 등록정보: 4-스토어-설명글.txt 내용, 아이콘·그래픽·스크린샷 업로드
4. 프로덕션(또는 내부 테스트) → 새 버전 만들기 → 5-...aab 업로드 → 출시 노트 → 검토 후 출시
5. ★ AAB 업로드 후 반드시: 설정 → 앱 무결성 → "앱 서명 키 인증서"의 SHA-256 지문을 복사해
   D:\00_WORK\000_앱개발\수능장소검색\ykwanghee-lab.github.io\.well-known\assetlinks.json 의
   kr.sayeonjjang.app 항목 sha256_cert_fingerprints 에 추가 후 푸시.
   (지금은 업로드 키 지문 8F:83:2F:...만 들어 있음. 이걸 안 하면 설치한 앱 위에 브라우저 주소창이 뜸)
